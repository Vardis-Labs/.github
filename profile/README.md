# Vartari Labs

Vartari Labs builds local-first AI applications powered by on-device models, MCP integrations, and privacy-focused workflows.

We create practical software that keeps data, intelligence, and control close to the user.

## What we build

- Local-first AI desktop applications
- MCP servers, connectors, and secure gateways
- AI-assisted tools for creators and developers
- Private workflows powered by local models
- Reusable infrastructure for running AI on your own hardware

## Current focus

### LaionSpeech

LaionSpeech is a local-first AI workspace for writing, worldbuilding, voice generation, and audiobook production.

The project combines local language models, speech-to-text, text-to-speech, Codex-style knowledge management, and MCP integrations in one private creative environment.

## Principles

- Local first
- Privacy by default
- User-owned data
- Modular architecture
- Open integrations
- Practical AI, not demos
